Circular icon-only button — the "my location", search and radar-playback controls.

\`\`\`jsx
<IconButton label="Mi ubicación"><Icon name="crosshair" size={17} /></IconButton>
<IconButton tone="glassOutlined" label="Buscar"><Icon name="search" size={16} /></IconButton>
<IconButton tone="gradient" size={34} label="Pausar"><Icon name="pause" size={12} /></IconButton>
\`\`\`

Always circular, never square. Use \`glass\`/\`glassOutlined\` only on top of the map, \`gradient\` only for the single play/pause control.
